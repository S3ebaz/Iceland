# 🇸🇮 Iceland - Epic Interactive Map

Mapa interactivo épico de Islandia con estilo de videojuego / cartografía de alivio.

## Características
- Mapa interactivo con **Leaflet.js**
- Marcadores para ciudades, glaciares, volcanes y puntos de interés épicos
- Popups con temperaturas promedio, descripciones y datos relevantes
- Estilo oscuro y dramático
- Datos en `data/locations.json`

## Estructura
```
/
├── index.html          # Mapa principal (GitHub Pages ready)
├── data/
│   └── locations.json   # Locaciones, clima, descripciones
├── assets/
│   └── images/          # Imágenes del mapa (sube aquí iceland-map.jpg)
└── README.md
```

## Cómo verlo
1. Activa **GitHub Pages** en Settings → Pages → Branch: main / root
2. O abre `index.html` localmente

## Próximos pasos
- Sube la imagen del mapa épico a `assets/images/iceland-map.jpg`
- Puedes cambiar el mapa base a imageOverlay si quieres usar tu mapa personalizado
